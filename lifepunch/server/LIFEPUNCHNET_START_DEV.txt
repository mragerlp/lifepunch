LIFEPUNCHNET — START DEVELOPMENT SERVER (paste into RDP PowerShell or CMD)
================================================================================
One folder: C:\S&BOX DXRP Server
One launcher: dotnet run dxrp-server.cs --token <DEVELOPMENT token>
Same RDP user for ALL steps (e.g. administrator). NOT elevated for start.

STEP 1 — Pull scripts (once)
--------------------------------------------------------------------------------
cd C:\lifepunch\lifepunch-rdp-server
git pull --rebase
cd lifepunch\server\dxrp-host\scripts
powershell -ExecutionPolicy Bypass -File .\Deploy-DxrpHostLaunchers.ps1

STEP 2 — Start dev server (every time after engine bump or Steam break)
--------------------------------------------------------------------------------
cd /d "C:\S&BOX DXRP Server"
start_dev_server.bat

CONSOLE LOST? (common after auto_update — server opened in hidden window)
  - Taskbar: look for window titled "LIFEPUNCH DEV SERVER"
  - Or double-click: show_dev_server_log.bat  (opens logs\dev-server-last.log in Notepad)
  - Or in CMD: type C:\S&BOX DXRP Server\logs\dev-server-last.log

  OR (same thing):

powershell -ExecutionPolicy Bypass -File "C:\S&BOX DXRP Server\Run-DevServer.ps1"

PASS in console:
  Connected to Steam
  dxrp-server [7/7]

FAIL → paste back ONLY:
  1) Steam line (connected / not connected)
  2) Last [N/7] line
  3) First red error block

DO NOT:
  - Create a second S&BOX DXRP Server folder
  - Run server1_start.bat (that is 70p Official)
  - Change ULX portal revisions to fix Steam
  - Run multiple server2_start / start_dev_server at once
  - Run Patch-LifepunchnetUlxCompile.ps1 (ULX is OFF your gamemode — not needed)

ULX OFF GAMEMODE — remove stale on-disk copy (one-time, if compile still mentions lifepunch.ulx):
  rmdir /S /Q "C:\S&BOX DXRP Server\dxrp\game\Code\Addons\lifepunch\dxrpadminmenu"
  rmdir /S /Q "C:\S&BOX DXRP Server\dev-patches"
  Then start_dev_server.bat again. Portal will NOT download ULX until you re-pin it.

Portal: Development server token lives in:
  C:\S&BOX DXRP Server\secure\development.local.env
  DXRP_TOKEN_DEVELOPMENT=<token from dxrp.net portal Development server>
