STEP 3 — WHISPER ON PORT 9000
--------------------------------------------------------------------------------

Once Docker is green:

  docker pull hwdsl2/whisper-server

  docker run -d --name whisper --restart unless-stopped ^
    -p 9000:9000 ^
    -e WHISPER_MODEL=small.en ^
    hwdsl2/whisper-server

Create test audio (or copy any short .wav):

  New-Item -ItemType Directory -Force -Path C:\lifepunch

Smoke test ON THIS BOX:

  curl.exe -X POST "http://127.0.0.1:9000/v1/audio/transcriptions" ^
    -F "file=@C:\lifepunch\test.wav" ^
    -F "model=small.en"

Success = JSON response with a "text" field.

Firewall: allow inbound 9000 only from trusted IPs (LAN / VENGEANCE / Cornerman).
Do not expose 9000 to the public internet unless you intend to.
