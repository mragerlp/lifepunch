# Maps

This folder is reserved for LifePunch mapping work.

Use it for map planning, source references, map-specific requirements, testing notes, and future mapping workflows that may support the DXRP gamemode.

Do not mix mapping work with:

- `../addons`: addon packages and publish staging.
- `../gamemode`: gamemode exports and revision pins.
- `../server`: hosted server configuration and server-page audits.
- `../portal`: DXRP portal tab documentation.
