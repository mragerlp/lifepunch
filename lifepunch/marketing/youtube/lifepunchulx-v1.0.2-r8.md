LIFEPUNCH ULX for DXRP — First production addon on the DXRP portal: permission-aware staff console, 25 admin actions, live roster, waypoints, and owner settings. Code-only · pin on your gamemode · open with lifepunchulx / menu / ulx.

Opens in-game: lifepunchulx · /lifepunchulx · menu · ulx · /menu · /ulx
Header: Admin Menu · ULX Console

⛶ WHAT IT IS
────────────────────────
Server-agnostic, ULX-style staff console for any DXRP.net server. Thin UI + dispatch over DXRP's native admin backend — every action permission-gated in the menu and re-validated on the host. No new authority.

⛶ FEATURES
────────────────────────
• 25 staff actions — Moderation, Commands, Ability
• Live player roster + profile pane (role, job, cash/bank, health, armor, playtime)
• Waypoints — go / set / clear + host-synced saved list
• Settings — network website URL, UI scale S/M/L/XL
• Network chip — header shows your saved network slug (e.g. dxrp.net → dxrp)
• LifePunch chrome — shared footer, ULX blue palette, click-to-copy feedback

⛶ SETUP
────────────────────────
1. Portal → Gamemode → Content → add lifepunchulx
2. Sync / restart dedicated servers
3. Portal → Ranks → grant DXRP admin permissions your staff need
4. In-game Settings → Network Management → save your site URL
