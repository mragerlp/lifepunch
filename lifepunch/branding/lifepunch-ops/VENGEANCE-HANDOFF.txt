OH-MY-POSH (every box)
----------------------
winget install --id JanDeDobbeleer.OhMyPosh -e --source winget

Do NOT use plain `oh-my-posh init ... | Invoke-Expression` — init can return empty on some
boxes. Apply-LifePunchOpsConsole.ps1 wires:

  function prompt { oh-my-posh print primary --config "<omp.json>" --shell pwsh|powershell }
