## Use the register

| Need | Go to |
|------|-------|
| Searchable decision by ID | `DECISIONS/README.md` |
| Under discussion | `RFC/README.md` |
| Learned context (not law) | `KNOWLEDGE/README.md` |
| Who owns what | `OWNERSHIP_MATRIX.md` |

**Distiller:** Cite `DECISION-0006`, do not re-explain hub upgrades in every outbox.

---

## Adding a decision

1. Create `DECISIONS/DECISION-####-Short-Title.md` from template in `DECISIONS/README.md`.
2. Add row to `DECISIONS/README.md` index.
3. Link from affected lane docs / knowledge files.

**Do not** append long entries here — one file per decision.
