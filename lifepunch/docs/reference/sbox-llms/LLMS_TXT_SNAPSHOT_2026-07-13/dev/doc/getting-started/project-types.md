# Project Types

When creating a new project in s&box you are presented with a few different project types to make.

- **[Game Project](/dev/doc/getting-started/project-types/game-project)** — the base level of project, which contains a game.
- **[Addon Project](/dev/doc/getting-started/project-types/addon-project)** — adds assets to an existing Game Project.


## The sbproj file

The .sbproj file holds your project's information like its title and type. It tells s&box that this is a project folder.
