# Editor

The s&box editor is your workspace for building games — scene editing, asset management, visual scripting, and more.

## [ActionGraph](/dev/doc/actiongraph)

Visual scripting system for creating logic without writing code.

## [Editor Tools](/dev/doc/editor/editor-tools)

Custom tools you can build to extend the editor for your game's needs.

## [Mapping](/dev/doc/editor/mapping)

Hammer-based map creation with brushwork, props, lights, and GameObjects.

## [Model Editor](/dev/doc/editor/model-editor)

ModelDoc-based model editing and configuration.
