# Decals

The `Decal` component projects textures onto opaque or transparent surfaces in the world.

## [Decal Component](/dev/doc/rendering/effects/decals/decal-component)

The component that draws a decal in the game world.

## [DecalDefinition](/dev/doc/rendering/effects/decals/decaldefinition)

The resource that describes what a single decal looks like.

## [Animated Effects](/dev/doc/rendering/effects/decals/animated-effects)

Animating decal properties over the decal's lifetime.

## [Lifetime](/dev/doc/rendering/effects/decals/lifetime)

How long a decal lives, looping, and transient behaviour.
