# Beams

The `BeamEffect` component draws animated line/laser effects, useful for things like tracers and lasers.

## [BeamEffect](/dev/doc/rendering/effects/beams/beameffect)

The component that draws and animates beams.

## [Tracers](/dev/doc/rendering/effects/beams/tracers)

Using a BeamEffect to make a tracer that travels from one point to another.
