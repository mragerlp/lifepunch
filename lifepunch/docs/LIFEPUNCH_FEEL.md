# LIFEPUNCH™ — Product feel (identity bar)

> **Why does this exist?** Mechanics docs say *how*; this doc says *what it should feel like* when we get it right.  
> **Use:** Fantasy Check, Architect Review, UX copy, asset direction.  
> **Parent:** `LIFEPUNCH_GAMEPLAY_LAWS.md` · **Words:** `TERMINOLOGY.md`

When two design options both compile, **feel** breaks the tie.

---

## One sentence

Players operate **premium industrial cyber infrastructure** on a serious roleplay server — not a mobile idle game, not a spreadsheet, not a theme park of NPC quest givers.

---

## Feel words (yes)

| Word | Means in practice |
|------|-------------------|
| **Premium** | Fewer objects, higher polish, intentional interaction |
| **Industrial** | Machines, states, lights, sound from real attachment points |
| **Purposeful** | Every button/tab/command earns its place |
| **Professional** | Operator fantasy — control room, daemon logs, telemetry |
| **Believable** | Vocabulary respects mining/banking/hacking without homework |
| **Readable** | 30-foot test; states obvious without opening menus |
| **Modern utility software** | Hub dashboards feel like ops tools, not gamey HUD spam |
| **Cyber infrastructure** | Players run systems, not collect stickers |
| **Minimal clutter** | Law 4 readability; no visual noise for realism's sake |
| **Roleplay-first** | Decisions support DXRP stories (crime, economy, jobs) |

---

## Anti-patterns (no)

| Never becomes | Why |
|---------------|-----|
| **Idle clicker** | AFK mining OK; mindless tap-to-win is not |
| **Spreadsheet simulator** | Caps and clarity beat unlimited columns |
| **Factory spam** | Quantity caps are feature, not bug |
| **Arcade toy** | Cartoon buttons, fake juice without state |
| **NPC quest hub** | Core loops are player-driven (Law G9) |
| **Wiki homework** | Upgrades explain themselves in-world (Law G1) |

---

## Sensory checklist (subjective QA)

Ask after flatgrass proof:

1. Does standing next to the machine feel like **equipment**?
2. Does powered vs off read in **under 2 seconds** without text?
3. Does the hub panel feel like **software you'd use at work**?
4. Does the terminal feel like a **real console** (scroll, copy, rig0)?
5. Would a DarkRP player **brag about this prop** on Discord?

Any "no" → design debt before owner sign-off, even if compile is green.
