# Deprecated documentation

> **Status:** Active (this index)  
> **Why does this exist?** Retire docs without deleting history. AI must not treat **Deprecated** files as current law.

---

## Process

1. Set source doc **Status: Deprecated** at top.
2. Add **Superseded by:** link.
3. Copy or move stale content here (optional — link-only is fine).
4. Update `DECISIONS/` or `KNOWLEDGE/` if the lesson matters.

---

## Status badge (all design docs)

```markdown
> **Status:** Active | Draft | Deprecated | Historical | Experimental
```

| Status | AI behavior |
|--------|-------------|
| **Active** | Current canon |
| **Draft** | RFC or in-progress — do not implement as law |
| **Deprecated** | Read for history only |
| **Historical** | Checkpoint / dated snapshot |
| **Experimental** | Playtest or spike — may be deleted |

Full standard: `KNOWLEDGE/README.md` · enforced in onboarding Block 0.
