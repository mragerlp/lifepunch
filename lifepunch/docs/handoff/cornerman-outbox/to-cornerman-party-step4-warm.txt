STYLE / CONVENTIONS (reuse Step 3)
  - Razor: @namespace Dxura.RP.Game.UI ; @inherits Panel ; @attribute [StyleSheet].
  - SCSS root selector uses the COMPONENT TYPE name (DXRP house style), not a class.
  - pointer-events: all | none ONLY (NOT "auto"). Root HUD is pointer-events:none
    until IsCursorUnlocked (Input.Down("Mouse") = Alt) -> "all".
  - Clickable: onclick="@Method" ; set child glyphs pointer-events:none so the whole
    bar/row routes to the parent handler.
  - PanelComponent/Panel BuildHash() MUST include every private UI flag that changes
    markup (open tab, collapsed, selected member, error/invite state).
  - Tokens: $color-primary #191919 ; $color-good #199c3b (cash) ;
    $counter-terror-color #08B2E3 (armor) ; $color-bad ; $color-gray-400 ;
    $rounding 2px ; $space-3 12px. Health bar uses DXRP native health gradient
    (see PlayerInfo HealthColorHex). Material icons: group, star, expand_more/less,
    favorite, shield, person_add, logout, close.
  - Reuse PartyMemberCard as the row template; the menu is a larger surface, same DNA.
  - Brand: DXRP is third-party; lead UI labels with the ACTION, not a third-party mark.
