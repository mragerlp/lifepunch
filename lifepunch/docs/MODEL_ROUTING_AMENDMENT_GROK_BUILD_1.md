1. **VERIFIED FROM REPO** — direct citation with file + line or section.
2. **INFERRED FROM EXISTING PATTERNS** — clear reasoning from canon.
3. **NEEDS SBOX-EDITOR PROOF** — requires ModelDoc / vmat / prefab inspection.
4. **NEEDS SBOX RUNTIME PROOF** — requires bridge / flatgrass / in-game verification.
5. **OWNER DECISION REQUIRED** — policy, economy, or visual identity call.
6. **OUT OF SCOPE** — quarantined lanes, blocked work, etc.
