## Lifecycle

```text
Architect drafts RFC-####-Topic.md  (Status: Draft)
        ↓
Owner + Architect debate
        ↓
Approved → DECISIONS/DECISION-####-*.md  (Status: Active)
        ↓
RFC Status → Accepted (link decision) or Deprecated
```

---

## Status values

| Status | Meaning |
|--------|---------|
| **Draft** | Open for comment — not implementation law |
| **Accepted** | Promoted to `DECISIONS/` — RFC kept as history |
| **Rejected** | Closed — move to `deprecated/rfc/` or mark Rejected |
| **Withdrawn** | Owner parked — link `BACKLOG_PARKING_LOT.md` |
