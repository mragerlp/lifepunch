# DECISION-0003 — No NPC core progression

> **Status:** Active  
> **Date:** 2026-06-25  
> **Owner:** Architect  
> **Supersedes:** —  
> **Law:** `LIFEPUNCH_GAMEPLAY_LAWS.md` G9

## Decision

LIFEPUNCH cyber systems **do not depend on NPCs** for core progression loops.

## Reason

Players operate real infrastructure (machines, economy, PvP) — not quest givers or static vendors. Aligns with industrial operator fantasy and DXRP roleplay.

## Alternatives considered

- NPC shopkeeper for upgrades — **rejected** as primary path
- NPC tutorial miner — **rejected**

## Systems affected

All future addons · Bitcoin · Banking · Hacker (when unlocked)

NPCs may appear later as **optional flavor only**.
