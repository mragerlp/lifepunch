# DECISION-0008 — Fantasy Check gate

> **Status:** Active  
> **Date:** 2026-06-25  
> **Proposed by:** Design Architect  
> **Approved by:** Bloodwave  
> **Supersedes:** —  
> **Doc:** `LIFEPUNCH_FEEL.md`

## Decision

After flatgrass playtest, **Fantasy Check** (one question) is mandatory before owner sign-off. Major slices also run full **Architect Review** drift checklist.

## Reason

Compile-green builds can still betray player fantasy. Separates "does it work?" from "does it feel like LIFEPUNCH™?"

## Alternatives considered

- Owner-only gut check with no doc — **rejected**

## Systems affected

`ARCHITECT.md` · `WORKFLOW_IDEATION_FIRST.md` · ship loop

## Fantasy Check question

> Does this still deliver the intended player fantasy?
