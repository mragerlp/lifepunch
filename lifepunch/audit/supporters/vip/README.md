This is for support and future donation automation review, not payment secrets or raw transaction data.

Observed rank state:

- VIP is a supporter/donator role, not an administrative role.
- VIP does not have wildcard access.
- `None` means no access.
- VIP should not grant portal, moderation, server management, economy, inventory, API key, or staff-permission access.
