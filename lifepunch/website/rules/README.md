# Website Rules

This folder tracks the public LifePunch rules page.

Public URL:

```text
https://lifepunch.co/rules
```

Example direct rule link:

```text
https://lifepunch.co/rules#no-staff-impersonation
```

Observed page behavior:

- Rules are public.
- Rules are grouped by section.
- Rules are searchable on the website.
- Rule text can be copied.
- Individual rules can be linked directly by anchor.

Operational rules:

- Keep `current-rules.md` as the public rules snapshot.
- Draft proposed rule edits separately before changing the website.
- Do not silently change enforcement-sensitive rules.
- Staff-facing interpretation notes should live in audit or admin docs, not replace public wording.
- Any website automation for search, copy, or anchor generation should preserve stable rule slugs.

Review checklist for future edits:

- Confirm the rule has a stable slug.
- Confirm direct links still work after edits.
- Confirm copy text is accurate.
- Confirm wording matches DXRP, S&box, Facepunch, and Steam requirements.
- Confirm staff can enforce it consistently.
