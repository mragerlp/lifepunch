# Discord copy

Source of truth for pinned posts and reusable Discord markdown.

## How to use

1. Open the file for the channel you are updating.
2. Copy everything **below** the leading HTML comment (Discord does not need the comment).
3. Paste into Discord. Custom server emojis (e.g. `:lifepunchlogo:`) must already exist on the server.
