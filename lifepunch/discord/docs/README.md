# Discord copy

Source of truth for pinned posts and reusable Discord markdown.

## How to use

1. Open the file for the channel you are updating.
2. For a straight paste, use `welcome-official-channel.raw.txt` (no repo notes).
3. Or use `welcome-official-channel.md` — copy everything **below** the leading HTML comment.
4. Paste into Discord. Custom server emojis (e.g. `:lifepunchlogo:`) must already exist on the server.

## Index

- `welcome-official-channel.raw.txt` — final pinned post; copy the whole file into Discord.
- `welcome-official-channel.md` — same copy with a short usage comment at the top.
