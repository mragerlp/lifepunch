# Sanctions

Purpose: manage moderation actions such as punishments, restrictions, or bans if supported by DXRP.

Operational rules:

- Sanctions must be auditable.
- Moderators may handle routine sanctions if the portal supports constrained permissions.
- Permanent bans, economy-impacting punishments, and staff sanctions should require Admin or higher.
- Do not store private player data in this repo unless needed for an incident report.

Portal confirmation needed:

- Exact sanction types.
- Role-specific sanction permissions.
- Appeal or expiration fields.
- Relationship between sanctions and audit entries.
