# DXRP Portal Areas

This folder mirrors DXRP public navigation and LifePunch areas visible in the authenticated DXRP portal, except Servers, which is promoted to `../server` because hosted server management needs its own first-class workspace.

The purpose is operational clarity: each portal tab gets a home for notes, screenshots, exports, procedures, and future automation plans without mixing them into addon package source.

Public DXRP navigation confirmed so far:

- Servers
- Addons
- Portal

Authenticated portal tabs confirmed so far:

- Settings > Network
- Dashboard
- Servers (tracked in `../server`)
- Players
- Game Modes
- Audit
- Maps
- Rulesets
- Ranks
- Inventory
- Addons
- Factions
- Sanctions

Authenticated overflow menu confirmed from Dashboard `...` menu:

- Maps
- Rulesets
- Ranks
- Inventory
- Addons
- Factions
- Sanctions

These dropdown pages are reserved for tomorrow's deeper screenshots. Until each page is reviewed, keep their docs as structure/procedure notes rather than final field references.

Sensitive portal values such as API keys and Discord webhook URLs belong in `../secure`, not tracked portal docs.

Player-level records should not be bulk-copied here. Store only procedures, schemas, and examples needed to manage the community safely.

Live portal field confirmation is still needed for most tabs because browser control became unavailable after the initial Addons inspection.
