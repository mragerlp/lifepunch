# Hacker PvP — infrastructure warfare

**Rule:** Running hacker or miner infra makes you a target.

---

## Attack matrix

| Victim | Attacker tool | Tier required |
|--------|---------------|---------------|
| Player wallet (on-hand cash) | `cornerman` / standard terminal | Standard |
| **Bitcoin Miner hub** + racks | `vengeance` / advanced terminal | Advanced |
| **Hacker server rack** | `vengeance` | Advanced |
| **Government datacenter** | `vengeance` | Advanced |
| Hacker standard terminal alone | — | No remote rack upgrades to steal |

---

## Defense matrix

| Defender asset | Upgrade home | Effect |
|----------------|--------------|--------|
| Bitcoin hub | Encryption tracks | Firewall, cipher, alert, cooldown, puzzle harden |
| Hacker rack | Detection, etc. | Lower alert on fail, faster puzzles, higher steal |
| Gov terminal | lifepunchnet ops (TBD) | Trace, audit, warrant stubs |

---

## Failed hack counterplay

| System | Trigger |
|--------|---------|
| DXRP `/panic` | Position ping — police/medics |
| Wanted status | Phase 2 governance |
| Miner Intrusion Alert | Defender-owned ping |
| Hacker Detection | Suppresses panic roll |

---

## Successful hack outcomes (Phase 2 economy)

| Target | Criminal gain | Victim loss |
|--------|---------------|-------------|
| Wallet | $1k–$2.5k band (pre-upgrade) | On-hand cash only |
| Miner hub | Capped BTC/cash steal | Balance + optional power OFF |
| Hacker rack | Disrupt upgrades / force OFF | Downtime + bragging rights |
| Gov treasury | High difficulty | City alert + warrant chain |

---

## RP beats

- Hacker mines BTC → rival vengeance hits hub → owner buys encryption → arms race.
- FBI traces vengeance session at datacenter → warrant → raid props.
- Mayor raises tax → city drip increases → criminals target fatter treasury.
